ГОЛОСОВЫЕ ЗАМЕТКИ — РАСПОЗНАВАНИЕ НА КОМПЬЮТЕРЕ
================================================

Как это работает: телефон кладёт запись в папку приложения на вашем
Яндекс Диске, эта программа на компьютере распознаёт её (Whisper large-v3-turbo
на видеокарте) и кладёт текст обратно. Если компьютер выключен, задание ждёт,
а телефон пишет «компьютер выключен».

Ничего дополнительно ставить не нужно: install.bat сам скачает всё необходимое.


ШАГ 1. Зарегистрировать приложение у Яндекса (один раз, 5 минут)
----------------------------------------------------------------
1. Откройте в браузере: https://oauth.yandex.ru/client/new
   и войдите в свой Яндекс.
2. Название: Голосовые заметки
   Платформа: Веб-сервисы
   Redirect URI: https://oauth.yandex.ru/verification_code
3. В списке доступов найдите «Яндекс Диск REST API» и отметьте
   «Доступ к папке приложения на Диске». Больше ничего не отмечайте.
4. Нажмите «Создать приложение» и скопируйте ClientID
   (строка из букв и цифр).


ШАГ 2. На телефоне
------------------
1. Приложение → Настройки → «Распознавание на компьютере».
2. Вставьте ClientID → «Получить ключ».
3. Яндекс спросит разрешение → «Разрешить» → покажет ключ. Скопируйте его.
4. Вернитесь в приложение, вставьте ключ → «Подключить» → «Проверить связь».
   Должно появиться «Всё работает». Если ошибка — пришлите снимок экрана.
5. Нажмите «Скопировать ключ для ПК» и перешлите ключ себе на компьютер
   (например, в «Избранное» Telegram).


ШАГ 3. На компьютере
--------------------
1. Дважды щёлкните install.bat в этой папке.
   Если Windows покажет «Система Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае».
2. Если Python не установлен, установщик поставит его сам и попросит
   закрыть окно и запустить install.bat ещё раз.
3. Дальше он скачает библиотеки и модель (около 3 ГБ, несколько минут).
4. Когда появится «Ключ:» — вставьте ключ (правый щелчок мыши в окне)
   и нажмите Enter.
5. В конце будет «Всё готово». Программа работает в фоне и сама
   запускается при входе в Windows.


ДРУГИЕ ФАЙЛЫ В ПАПКЕ
--------------------
show-log.bat   — открыть журнал работы (в Блокноте)
restart.bat    — перезапустить программу
uninstall.bat  — выключить и убрать из автозапуска

Ключ хранится только на этом компьютере
(%APPDATA%\voice-notes-agent\token.txt) и даёт доступ лишь к папке
этого приложения на Диске, а не ко всему Диску.

ОБНОВЛЕНИЕ ПРОГРАММЫ
--------------------
Скачайте новый архив, распакуйте поверх старой папки и дважды щёлкните
install.bat. Когда спросит «Ключ:», просто нажмите Enter — старый ключ
останется.
