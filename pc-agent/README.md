# Распознавание на компьютере

Телефон кладёт аудио заметки в папку приложения на вашем Яндекс Диске
(`Приложения/<имя приложения>/jobs`). Программа на компьютере забирает его, распознаёт
моделью Whisper **large-v3-turbo** на видеокарте и кладёт текст обратно (`results`).
Если компьютер выключен — задание ждёт на Диске, а телефон пишет «компьютер выключен».

## Один раз: зарегистрировать приложение у Яндекса (5 минут)

1. Откройте https://oauth.yandex.ru/client/new (войдите в свой Яндекс).
2. Название: **Голосовые заметки**. Платформа: **Веб-сервисы**.
   Redirect URI: `https://oauth.yandex.ru/verification_code`
3. Доступы: найдите **Яндекс Диск REST API** и отметьте
   **«Доступ к папке приложения на Диске»** (больше ничего не нужно).
4. Нажмите «Создать приложение» и скопируйте **ClientID**.

## На телефоне

1. Настройки → «Распознавание на компьютере» → вставьте ClientID → **«Получить ключ»**.
2. Яндекс спросит разрешение → «Разрешить» → покажет ключ (длинная строка). Скопируйте его.
3. Вернитесь в приложение, вставьте ключ → **«Подключить»** → **«Проверить связь»**.
4. Нажмите **«Скопировать ключ для ПК»** и перешлите его себе на компьютер
   (например, в «Избранное» Telegram).

## На компьютере

1. Откройте папку `pc-agent` и дважды щёлкните **install.bat**.
2. Установщик сам поставит Python (если его нет — потом попросит запустить ещё раз),
   библиотеки и модель (~3 ГБ всего, первый раз несколько минут).
3. Когда спросит ключ — вставьте его (правый клик в окне) и нажмите Enter.
4. Готово: программа работает в фоне и сама запускается при входе в Windows.

Другие файлы: **show-log.bat** — журнал работы, **restart.bat** — перезапуск (и обновление
из этой папки), **uninstall.bat** — выключить и убрать из автозапуска.
Настройки — `%APPDATA%\voice-notes-agent\config.json` (модель, видеокарта/процессор).

Ключ хранится только в `%APPDATA%\voice-notes-agent\token.txt` и даёт доступ
лишь к папке этого приложения на Диске, не ко всему Диску.
