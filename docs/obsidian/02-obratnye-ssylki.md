# ТЗ 02. Обратные ссылки: упоминания, контекст, переименование, псевдонимы

Статус: не начато. Сложность: малая. Зависимости: нет.

## Что уже есть
Блок «Ссылаются сюда» в каждой заметке (`renderNote`, `backlinks`): список заметок, где есть `[[Название]]` на эту. Сравнение по `titleOf` и `n.title`.

## Как в Obsidian сейчас
- **Linked mentions**: заметки со ссылкой, с куском текста вокруг ссылки.
- **Unlinked mentions**: заметки, где название встречается обычным текстом, с кнопкой «Связать».
- Сортировка, поиск по обратным ссылкам, можно встроить список обратных ссылок в саму заметку.
- При переименовании заметки ссылки на неё во всех заметках обновляются автоматически.
- Свойство `aliases`: другие названия заметки, ссылки по ним тоже считаются.

## Что сделать
1. **Контекст**: под каждой обратной ссылкой показывать предложение, в котором стоит ссылка (≈120 символов, ссылка подсвечена). Нажатие на кусок открывает ту заметку.
2. **Упоминания без ссылки**: отдельный свёрнутый блок «Упоминания без ссылки (N)». Ищем название и псевдонимы с учётом падежей (уже есть `stem`/`sameStem` из v1.4). Кнопка «Связать» превращает упоминание в `[[Название|слово]]` в той заметке (с записью в «Прежние варианты»).
3. **Переименование**: когда меняется поле заголовка (`#ntitle`) и на старое имя есть ссылки, после окончания ввода (потеря фокуса) спросить: «Обновить N ссылок на новое название?». При согласии заменить `[[Старое]]` → `[[Новое]]` и `[[Старое|x]]` → `[[Новое|x]]` во всех заметках. Для заметок без явного заголовка (имя из первых слов) то же самое при первой правке текста, которая меняет `titleOf`.
4. **Псевдонимы**: поле «Другие названия» (через запятую) в заметке; хранится в `note.aliases` (массив). `findByTitle`, обратные ссылки, подсказки и выбор заметки учитывают псевдонимы. До ТЗ 03 это отдельное поле, после ТЗ 03 становится свойством `aliases`.
5. Счётчик обратных ссылок в карточке списка (рядом с 🔗): «↩ N».

## Хранение
`note.aliases: string[]`. Экспорт: `aliases:` в YAML-шапке.

## Трудности
- Заметки без заголовка называются по первым 7 словам и «…». Ссылка на такое имя ломается при любой правке начала текста. Поэтому при «Связать» на заметку без заголовка предлагать сразу задать ей заголовок (её `titleOf` записывается в `n.title`).
- Поиск упоминаний по всем заметкам при каждом открытии: при сотнях заметок это быстро, но считать только при открытии блока.

## Готово, когда
- В заметке «Ремонт» видно, где именно на неё ссылаются, и видны заметки со словом «ремонта» без ссылки; кнопка «Связать» делает ссылку.
- Переименование «Ремонт» → «Ремонт кухни» обновляет все ссылки, ничего не теряется.
- Ссылка `[[Кухня]]` открывает «Ремонт кухни», если у неё псевдоним «Кухня».
