# ТЗ 08. Граф связей

Статус: не начато. Сложность: средняя. Зависимости: нет (лучше после 02).

## Как в Obsidian сейчас
Глобальный граф (все заметки) и локальный (связи текущей заметки с ползунком глубины). Фильтры: поиск, метки, вложения, только существующие, «сироты». Группы с цветами по поисковому запросу. Настройки сил (притяжение, отталкивание, длина связи). Анимация «как росло хранилище» по времени создания. Стрелки направлений.

## Что сделать
1. Экран «Граф» (`#/graph`): узлы = заметки (размер по числу связей), линии = ссылки `[[...]]`. Отдельные узлы для несуществующих заметок (бледные), по нажатию «Создать?».
2. Цвет узла = проект. Метки как узлы: переключатель «Показывать метки».
3. Жесты: перетаскивание одним пальцем двигает граф, двумя масштабирует, нажатие на узел подсвечивает соседей и показывает название, второе нажатие открывает заметку.
4. **Локальный граф** в заметке: маленький блок «Граф связей» (свёрнут по умолчанию) с глубиной 1–2.
5. Фильтры: проект, метка, «скрыть одиночные».
6. Анимация роста по `createdAt` (кнопка ▶) — по желанию, последним шагом.

## Техника
- Рисование на `<canvas>` (не SVG): быстрее при сотнях узлов.
- Раскладка: своя простая силовая модель (≈150 строк) или `d3-force` с jsDelivr (≈30 КБ, кэшировать в service worker для офлайна). Рекомендую d3-force: проверенная, маленькая.
- Считать раскладку пачками по кадрам (`requestAnimationFrame`) и останавливать, когда успокоилась, чтобы не грела телефон.
- Модуль `graph.js`, грузится только при открытии экрана.

## Трудности
- Сейчас ссылок мало, граф будет из одиночных точек. Польза растёт вместе с ТЗ 02 (упоминания → ссылки) и подсказками ссылок.
- Мелкие подписи на телефоне: показывать подписи только при приближении и у выбранного узла.
- Производительность в Safari при 1000+ заметках: ограничить отрисовку подписей, при необходимости упростить.

## Готово, когда
- На iPhone граф из 200 заметок открывается быстрее 2 секунд, двигается плавно, нажатие открывает заметку.
- Локальный граф в заметке показывает её соседей.
