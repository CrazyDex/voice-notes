# ТЗ 03. Свойства заметок

Статус: не начато. Сложность: средняя. Зависимости: нет. От него зависят: 07 (базы), 04, 05.

## Как в Obsidian сейчас
Свойства хранятся в YAML-шапке файла. Типы: текст, список, число, флажок, дата, дата и время, метки. Встроенные: `tags`, `aliases`, `cssclasses`. Есть общий список всех свойств хранилища, поиск по свойствам, переименование свойства во всех заметках, ссылки `[[…]]` внутри свойств (с 1.11 обновляются при переименовании).

## Что у нас похожее
`createdAt`, `projectId` (проект), `tags`, `duration`, `source`. Пользовательских полей нет.

## Что сделать
1. Блок «Свойства» под заголовком заметки, свёрнут, если пуст. Строка = название + значение. Кнопка «+ свойство».
2. Типы: текст, число, флажок, дата, дата и время, список (чипы), ссылка на заметку (выбор через существующий `pickNote`). Ввод даты через системный `<input type=date>` (на iPhone колёсико).
3. При добавлении свойства подсказывать уже существующие названия свойств (из всех заметок) и их тип.
4. Готовые свойства для быстрого выбора: `статус` (список: идея/в работе/готово), `срок` (дата), `приоритет` (число 1–3).
5. Экран «Свойства» в настройках: все свойства, сколько заметок их используют, переименовать, сменить тип, удалить из всех заметок.
6. Поиск: `статус:готово`, `срок<2026-10-10`, `есть:срок` (часть общих операторов поиска, ТЗ 12).
7. Экспорт: свойства в YAML-шапку (рядом с created/project/tags). Импорт JSON-копии переносит их.

## Хранение
`note.props = { 'статус': 'в работе', 'срок': '2026-10-10' }`. Схема типов отдельно: `localStorage vn.propTypes` или запись в store `projects`. Лучше в IndexedDB (новый store `meta`), чтобы попадало в резервную копию и синхронизацию.

## Трудности
- Удобный ввод на маленьком экране, клавиатура закрывает поля. Делать редактирование свойства в нижней шторке (`sheet`), как выбор проекта.
- Совместимость с Obsidian: русские названия свойств Obsidian понимает, но значения дат должны быть в формате `YYYY-MM-DD`.
- Решить, становится ли «Проект» свойством. Предложение: оставить проект как есть (это папка при экспорте), свойства отдельно.

## Готово, когда
- Можно добавить заметке «статус» и «срок», они видны, сохраняются, ищутся.
- В экспорте у заметки YAML-шапка со свойствами, Obsidian показывает их в своём блоке свойств.
- Переименование свойства в настройках меняет его во всех заметках.
