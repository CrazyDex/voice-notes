# ТЗ 04. Ежедневные заметки и шаблоны

Статус: не начато. Сложность: малая. Зависимости: желательно 01 (чек-листы в шаблонах), 03 (свойства в шаблонах).

## Как в Obsidian сейчас
- **Daily notes**: команда «Открыть сегодняшнюю», имя по формату даты (с 1.11 есть готовые форматы), папка, шаблон, можно открывать при запуске, переход на вчера/завтра, свойство-дата становится ссылкой на ежедневную заметку.
- **Templates**: папка шаблонов, вставка шаблона в заметку, переменные `{{date}}`, `{{time}}`, `{{title}}`.
- **Unique note creator**: новая заметка с именем-временем.

## Что сделать
### Ежедневные заметки
1. Кнопка «📅 Сегодня» на главном экране: открывает (или создаёт) заметку с заголовком `2026-10-04` (формат выбирается в настройках: `2026-10-04`, `04.10.2026`, `4 октября 2026`).
2. В ежедневной заметке стрелки «‹ вчера» / «завтра ›» (по существующим ежедневным заметкам).
3. **Голос в ежедневную**: настройка «Куда писать запись»: «Новая заметка» (как сейчас) или «В сегодняшнюю». Во втором случае запись дописывается в конец ежедневной заметки с временем: `**14:32** текст…`. Аудио сохраняется отдельным куском, ссылка из строки.
4. Свойство `тип: ежедневная` (после ТЗ 03) или флаг `note.daily = '2026-10-04'`, чтобы такие заметки можно было скрыть из общего списка фильтром-чипом.
5. Настройка «При запуске открывать»: список / сегодняшнюю заметку.

### Шаблоны
1. Шаблон = обычная заметка с меткой `#шаблон` (или в проекте «Шаблоны»). Так их можно создавать и править тем же интерфейсом.
2. Кнопка «Шаблон» в правке: выбор шаблона, вставка в позицию курсора. Переменные: `{{дата}}`, `{{время}}`, `{{заголовок}}`, `{{курсор}}` (и английские `{{date}}`, `{{time}}`, `{{title}}`).
3. Шаблон для ежедневной заметки выбирается в настройках.
4. Шаблон по умолчанию для проекта: новая запись в проекте начинается с шаблона (например «Баг: … Шаги: … Ожидалось: …»).
5. Шаблон может задавать свойства (после ТЗ 03) и метки.

## Хранение
Ничего нового, кроме настроек и `note.daily`. Шаблоны обычные заметки. В экспорте ежедневные можно класть в папку `Ежедневные/`.

## Трудности
- Распознавание дописывается в чужую (ежедневную) заметку, пока пользователь её, может быть, правит. Нужно дописывать только в конец и не трогать уже изменённый текст (по аналогии с защитой правок в v1.2).
- Часовой пояс: «сегодня» считать по местному времени, не по UTC.

## Готово, когда
- «📅 Сегодня» дважды подряд открывает одну и ту же заметку; завтра создаётся новая.
- Запись в режиме «В сегодняшнюю» дописывается с временем, аудио доступно.
- Шаблон с `{{дата}}` вставляется с сегодняшней датой.
