# ТЗ 10. Холсты (Canvas)

Статус: не начато, **рекомендую делать последним**. Сложность: большая. Зависимости: 01.

## Как в Obsidian сейчас
Бесконечная доска: карточки-заметки, текстовые карточки, картинки, ссылки, группы, стрелки между карточками с подписями, цвета. Открытый формат JSON Canvas (`.canvas`), холст можно встроить в заметку.

## Что сделать
1. Экран «Холсты»: список холстов, создание.
2. Холст: добавить карточку-заметку (выбор через `pickNote`), текстовую карточку, голосовую карточку (записать прямо на холст).
3. Перемещение карточек, изменение размера, стрелки между карточками (протянуть от края), цвета, группы.
4. Масштаб и прокрутка двумя пальцами, кнопка «вписать всё».
5. Нажатие на карточку-заметку открывает заметку, текст на карточке показывается по ТЗ 01.
6. Экспорт в `.canvas` (формат JSON Canvas: https://jsoncanvas.org) в общем экспорте, чтобы холст открылся в Obsidian.

## Хранение
Store `canvases` в IndexedDB: `{ id, name, nodes: [...], edges: [...] }` по спецификации JSON Canvas, чтобы экспорт был просто сохранением.

## Трудности
- Главная: работа пальцами на экране 6,7": точное перетаскивание, протягивание стрелок, отличие «двигаю карточку» от «двигаю доску». В Obsidian на телефоне холсты тоже неудобны.
- Свой движок перетаскивания/масштаба на Pointer Events и CSS transform: сотни строк и много проверок на iPhone.
- Для голосовых заметок польза меньше, чем у баз и задач.

## Готово, когда
- Можно разложить 10 заметок по доске, соединить стрелками, закрыть и открыть с тем же видом.
- Экспортированный `.canvas` открывается в Obsidian.
