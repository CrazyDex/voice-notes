Этот файл Claude Code читает автоматически. Здесь всё, что было решено и сделано в предыдущем чате (Cowork, 3–4 октября 2026).

## Архитектура (чистый статический сайт, без сборки)
- `index.html` — разметка + весь CSS (тёмная/светлая тема), регистрация SW, однократная перезагрузка для cross-origin isolation.
- `app.js` — вся логика UI: IndexedDB (`voicenotes`: stores `notes`, `projects`, `audio`), роутинг по hash (`#/`, `#/n/<id>`, `#/settings`, `#/projects`), запись, очередь распознавания, проекты/метки/связи, экспорт (.zip через JSZip с cdnjs, JSON-копия), защита от вылетов.
- `audio.js` — микрофон (AudioWorklet) → ресемплинг в 16 кГц → нарезка по паузам (энергетический VAD, кадры 20 мс, адаптивный порог шума) → WAV.
- `asr-worker.js` — Web Worker (module): Whisper через `@huggingface/transformers@3.7.1` с jsDelivr, модели с Hugging Face (кэшируются браузером). Кандидаты: `onnx-community/whisper-{base,small}`, запасные `Xenova/whisper-*`, medium — `Xenova/whisper-medium`. dtype: CPU → q8; WebGPU → encoder fp16/fp32 + decoder q4.
- `sw.js` — офлайн-кэш (network-first для своих файлов, cache-first для CDN) + добавляет заголовки COOP/COEP (многопоточный WASM на GitHub Pages).
- Версия задаётся в `app.js` (`VERSION`) и в query-строках `?v=` в `index.html` и `app.js` — **при каждом релизе менять везде синхронно** и поднимать имя кэша `SHELL` в `sw.js`. С v1.0 приложение само сверяет `VERSION` из свежего `app.js` на сайте и показывает плашку «Есть новая версия → Обновить» (плюс кнопка «Проверить обновления» в настройках) — пользователю больше не нужно переустанавливать иконку.

## Ключевые решения и выводы
- Whisper всегда обрабатывает окно 30 с: время на кусок почти не зависит от его длины → на медленных устройствах выгоднее длинные куски (настройка 8/12/20/28 с).
- **iPhone/Safari:** WebGPU-вариант Small (~350 МБ: encoder fp16 179 МБ + decoder q4 170 МБ) вызывал вылет вкладки по памяти. Поэтому на iOS «Авто» = CPU (q8). Medium на iPhone в браузере не жизнеспособен.
- Защита: перед загрузкой модели ставится метка `vn.loading` в localStorage; если при старте она есть — был вылет → откат WebGPU→CPU, затем Small→Base, показывается предупреждение.
- Запись автосохраняется кусками каждые 5 с (`<id>:p<n>` в store `audio`); после вылета собирается обратно, заметка помечается `recovered`, можно «Перераспознать».
- Фильтр галлюцинаций Whisper на тишине («Субтитры сделал DimaTorzok», «Продолжение следует» и т. п.).
- iOS останавливает запись в PWA при блокировке экрана/сворачивании — ограничение платформы; используется Wake Lock.
