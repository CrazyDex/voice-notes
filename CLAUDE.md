## Архитектура (чистый статический сайт, без сборки)
- `index.html` — разметка + весь CSS (тёмная/светлая тема), регистрация SW, однократная перезагрузка для cross-origin isolation.
- `app.js` — вся логика UI: IndexedDB (`voicenotes`: stores `notes`, `projects`, `audio`), роутинг по hash (`#/`, `#/n/<id>`, `#/settings`, `#/projects`), запись, очередь распознавания, проекты/метки/связи, экспорт (.zip через JSZip с cdnjs, JSON-копия), защита от вылетов.
- `audio.js` — микрофон (AudioWorklet) → ресемплинг в 16 кГц → нарезка по паузам (энергетический VAD, кадры 20 мс, адаптивный порог шума) → WAV.
- `asr-worker.js` — Web Worker (module): Whisper через `@huggingface/transformers@3.7.1` с jsDelivr, модели с Hugging Face (кэшируются браузером). Кандидаты: `onnx-community/whisper-{base,small}`, запасные `Xenova/whisper-*`, medium — `Xenova/whisper-medium`. dtype: CPU → q8; WebGPU → encoder fp16/fp32 + decoder q4.
- `sw.js` — офлайн-кэш (network-first для своих файлов, cache-first для CDN) + добавляет заголовки COOP/COEP (многопоточный WASM на GitHub Pages).
- Версия задаётся в `app.js` (`VERSION`) и в query-строках `?v=` в `index.html` и `app.js` — **при каждом релизе менять везде синхронно** и поднимать имя кэша `SHELL` в `sw.js`. С v1.0 приложение само сверяет `VERSION` из свежего `app.js` на сайте и показывает плашку «Есть новая версия → Обновить» (плюс кнопка «Проверить обновления» в настройках) — пользователю больше не нужно переустанавливать иконку.

## Ключевые решения и выводы
- Whisper всегда обрабатывает окно 30 с: время на кусок почти не зависит от его длины → на медленных устройствах выгоднее длинные куски (настройка 8/12/20/28 с).
- **iPhone/Safari:** WebGPU-вариант Small (~350 МБ: encoder fp16 179 МБ + decoder q4 170 МБ) вызывал вылет вкладки по памяти. Поэтому на iOS «Авто» = CPU (q8). Medium на iPhone в браузере не жизнеспособен.
- Защита: перед загрузкой модели ставится метка `vn.loading` в localStorage; если при старте она есть — был вылет → откат WebGPU→CPU, затем Small→Base, показывается предупреждение.
- Запись автосохраняется кусками каждые 5 с (`<id>:p<n>` в store `audio`); после вылета собирается обратно, заметка помечается `recovered`, можно «Перераспознать».
- Фильтр галлюцинаций Whisper на тишине («Субтитры сделал DimaTorzok», «Продолжение следует» и т. п.).
- iOS останавливает запись в PWA при блокировке экрана/сворачивании — ограничение платформы; используется Wake Lock.

## Текущее состояние
- 04.10.2026: v0.3 опубликована (git подключён, `.nojekyll`). На iPhone v0.3 вылетала через несколько секунд («повторно возникла проблема») — вероятно, первая запись сама грузила Small.
- **v0.4** (ответ на вылеты): на iOS по умолчанию Base, разовая миграция Small→Base (`vn.mig04`); на iOS нет COOP/COEP и один поток WASM; добавлена модель Tiny; журнал шагов `vn.log` (видно в Настройки → Диагностика, кнопка «Скопировать журнал»); детект вылета по метке `vn.alive`; после вылета модель понижается (…→Base→Tiny) и включается `vn.safe` — модель не грузится сама при записи, только кнопкой.
- v0.5–0.6: журнал показал, что Whisper в Safari на iPhone падает именно во время распознавания (даже Tiny, 7-секундный кусок), и считает ~в 10 раз медленнее ПК (Base: 24 с на кусок против 2,6 с). Пользователь решил: Whisper в браузере iPhone — тупик.
- **v0.7**: добавлен движок «Встроенное» (Web Speech API, `webkitSpeechRecognition`, на iOS = диктовка Siri) — настройка `engine` (`sys`/`whisper`), на iOS по умолчанию `sys`. Сессии перезапускаются, пока идёт запись; параллельно пишется звук; если микрофон конфликтует (`audio-capture`) — дальше только текст (`vn.sysNoRec`). На iPhone **работает** (подтверждено 04.10), но Apple не ставит знаков — в v0.9 добавлена авто-пунктуация (`punctuate`: голосовые команды «запятая/точка/…», точка перед заглавной и в конце фразы). v0.8: на iOS скрыто «Перераспознать» (Whisper там падает).
- **v1.1**: импорт аудиофайлов (кнопка со стрелкой на главном экране, можно несколько файлов) — для голосовых из Telegram (.ogg/.oga Opus) и любых других. `decodeAudioFile` в `audio.js`: сначала `decodeAudioData` браузера (OfflineAudioContext 16 кГц), если не вышло и файл Ogg — свой декодер `vendor/ogg-opus-decoder.min.js` (ogg-opus-decoder 1.7.5, MIT, WASM внутри). Аудио всегда сохраняется (WAV 16 кГц), заметка помечена `source: 'file'`, `fileName`. Распознаётся только Whisper'ом и только не на iOS: Web Speech слушает лишь микрофон, Whisper в Safari вылетает — на iPhone заметка без текста с пояснением. На iOS у `<input type=file>` нет `accept`, иначе .ogg серые в «Файлах».
- **v1.2**: «Распознавание на компьютере» через Яндекс Диск (выбор Дениса). `pc.js` — клиент REST API Диска + пословный diff. Телефон кладёт WAV в `app:/jobs/<noteId>.wav` (свойства lang, sentAt), программа `pc-agent/vn_agent.py` (faster-whisper large-v3-turbo, на GTX 1050 4 ГБ — cuda int8, запасной CPU int8; автозапуск через Планировщик, `install.bat`) кладёт `app:/results/<noteId>.json` и раз в минуту ставит `seen` в custom_properties `app:/pc.json` (по нему «ПК в сети/выключен», порог 3 мин). Ключ: OAuth-приложение Дениса с доступом только к папке приложения, redirect `https://oauth.yandex.ru/verification_code`; ClientID и ключ хранятся в localStorage (`vn.ydClient`, `vn.ydToken`), на ПК — `%APPDATA%\voice-notes-agent\token.txt`. Защита правок: `note.pc.base` = текст в момент отправки; если не меняли — текст заменяется, старый уходит в `note.versions`; если меняли — `note.pcText` + плашка «Сравнить / Заменить / Добавить ниже / Оставить мой». Инструкция для Дениса — `pc-agent/README.txt` (UTF-8 с BOM, CRLF): на его ПК нет программ для .md, инструкции только .txt/.html. Скачивание файлов с Диска из браузера (CORS downloader) не проверено на живом Диске — кнопка «Проверить связь» в настройках это проверяет.
- pc-agent 1.1–1.2 (04.10): отметка «в сети» в отдельном потоке (иначе во время загрузки модели телефон считал ПК выключенным); обход системного прокси Windows (`proxy_fix.py`: https://→http://, при неудаче — напрямую, `proxy.json`); пунктуация на длинных записях: `initial_prompt`-образец + `condition_on_previous_text=True`, точка и заглавная на паузах. **Подтверждено Денисом: на его ПК работает (видеокарта), качество turbo его устраивает.** Если захочет короткие предложения «как у Claude» — нужен локальный LLM-редактор после Whisper (~2 ГБ влезет в GTX 1050), пока не делали.
- **v1.4** (04.10): ссылки с подписью `[[Заметка|текст]]` (как в Obsidian): «Связать» при выделенном тексте оставляет слово в тексте и ведёт на выбранную заметку (раньше выделение заменялось названием цели — Денис принял это за баг); поиск в выборе заметки заранее заполнен выделением и понимает падежи; «# Метка» с выделением ставит метку после слова. Блок «Подсказки» под текстом заметки: существующие метки и явные заголовки других заметок, чьи слова встречаются в тексте (`suggestFor`: грубый стемминг русских окончаний, без моделей). Нажатие на метку добавляет её чипом, на ссылку — оборачивает найденный фрагмент в `[[Название|фрагмент]]`; «Скрыть» запоминает отказ в `note.sugHidden`.
- Обсуждали серверное распознавание: ПК пользователя (faster-whisper + Tailscale) годится только для личного пользования; для многих людей — встроенное или платный облачный API через свой прокси.
